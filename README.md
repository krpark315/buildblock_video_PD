# 빌드블럭 댓글 페르소나 분석

빌드블럭 Instagram 릴스와 YouTube 영상에 달린 **공개 댓글 53건**을 근거로 페르소나 4명을 도출하고, 각 페르소나가 어떤 댓글에서 나왔는지를 원문과 원본 링크로 되짚어 확인할 수 있게 만든 자료입니다.

사이트가 아니라 **댓글 검증 자료를 취합해 "페르소나는 이것이다"를 보여 주는 문서**입니다.

## 열어 보기

`index.html`을 브라우저로 바로 열어도 되고, 로컬 서버로 띄워도 됩니다.

```bash
python3 -m http.server 4180 --bind 127.0.0.1
```

GitHub Pages를 켜면 저장소 그대로 배포됩니다. 빌드 과정이 없는 정적 파일이고, 외부 CDN·웹폰트에 의존하지 않습니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 본문. 01 분석 콘텐츠 → 02 페르소나 → 03 반복 주제 → 04 분석 방법 → 05 시리즈 방향 → 06 영상별 분석 |
| `archive/index.html` | 댓글 원문 53건 아카이브. 플랫폼·주제·키워드·콘텐츠 필터와 4종 정렬 |
| `data/report-data.js` | 통합 데이터. `window.BB`로 노출 |
| `app.js` · `styles.css` | 두 페이지 공용 렌더링과 스타일 |
| `assets/thumbs/` | 분석 대상 콘텐츠 썸네일 18장 |
| `docs/` | 시리즈 방향 10가지, K-뷰티 1호점 임장기 브레인스토밍 자료 |
| `scripts/` | 데이터 빌드 스크립트 (아래 참고) |

캡처를 포함한 내부 검증본은 별도로 보관하며, 이 저장소에는 포함하지 않습니다.

## 분석 범위

- Instagram 릴스 **60편 중 댓글이 달린 16편**, YouTube **8편 중 댓글이 달린 2편** — 총 18편
- 댓글 53건 = 외부 작성자 48건 + 빌드블럭 공식 답글 5건
- 계정 41개 (공개 23 / 비공개 18)
- 수집일 2026-07-31

댓글이 하나도 달리지 않은 콘텐츠는 제외했습니다. 좋아요를 누른 계정 목록으로 보완하려 했으나, Instagram은 좋아요 리스트를 게시물 소유자에게만 노출하고 YouTube는 명단 자체를 제공하지 않아 불가능했습니다.

## 검증 방법

페르소나 카드마다 근거가 된 댓글을 원문 그대로 싣고, 각 댓글에 **원본 게시물 링크**와 **댓글 링크**를 붙였습니다. 주장 → 근거 댓글 → 실제 게시물까지 한 번에 되짚을 수 있습니다.

아카이브에서는 댓글 53건 전체를 플랫폼·주제·키워드·콘텐츠로 걸러 보고, 영상순/주제순/공감순/길이순으로 정렬할 수 있습니다.

## 개인정보 처리

이 저장소는 **공개 배포본**입니다. 타인의 개인정보가 남지 않도록 다음을 적용했습니다.

- 댓글 작성 계정은 전부 **`A001` 형식으로 마스킹**했습니다. 실제 계정명은 데이터·문서 어디에도 없습니다.
- 공식 답글 안의 멘션도 작성자 ID로 치환했고, 매핑되지 않는 멘션은 `[작성자]`로 덮었습니다.
- **댓글 화면 캡처는 포함하지 않습니다.** 캡처 이미지에는 실제 계정명과 프로필 사진이 남기 때문입니다.
- 작성자 프로필 캡처 41장도 제외했습니다.
- 빌드블럭 공식 계정은 법인 계정이므로 그대로 표기합니다.

댓글 원문은 공개 게시물에 달린 것을 익명 처리해 인용했습니다. 각 댓글에는 원본 게시물 링크와 댓글 링크가 붙어 있어, 검증이 필요하면 실제 게시물에서 확인할 수 있습니다.

포함된 이미지 18장은 전부 빌드블럭 자체 콘텐츠의 썸네일입니다.

## 페르소나 판독 규칙

페르소나 카드는 6개 항목을 이 순서로 씁니다.

1. 이름 — `페르소나 가상 고객 : <어떤 사람인지 한 줄>`
2. 기본 프로필 — 연령대, 성별, 직업, 상황
3. 현재 상황 — 생활 배경과 처한 맥락
4. 주요 고민·고통 — 경제적, 시간적, 심리적 문제
5. 가장 바라는 변화 — 욕구와 목표
6. 실제로 검색할 만한 질문 3개

### 연령·성별·직업은 가설입니다

원자료는 프로필 사진이나 닉네임으로 나이와 성별을 추정하지 않는 원칙으로 수집됐기 때문에 그 값이 존재하지 않습니다. 인물상은 두 가지 근거로만 구성했습니다.

- **댓글에서 작성자가 스스로 밝힌 정보** — `미국 유학 아빠예유`, `맞벌이 부부는 트죠 냉동식품이`, `현지인입니다`, `달라스는 없다고 하는데`
- **공개 프로필에서 관찰된 직업 신호** — 세무·회계·투자, 한복 촬영 사업, 실리콘밸리 레스토랑 운영, 창업·건축·F&B

각 페르소나는 실제 특정 인물이 아니라 여러 사람을 합친 가상 고객입니다. 카드의 기본 프로필에 `가설` 배지를 달았고, "근거 댓글 보기"를 열면 근거를 문장 단위로 확인할 수 있습니다.

## 디자인

빌드블럭 공식 사이트의 UI를 기준으로 맞췄습니다. 검정 헤더·푸터, 흰 본문, 퍼플 단일 강조입니다.

| 항목 | 값 |
| --- | --- |
| 헤더·푸터 | `#000000` |
| 본문 배경 | `#ffffff` |
| 강조 (유일) | `#9333ea` · 밝은 변형 `#a855f7` · hover `#7e22ce` |
| 텍스트 | 본문 `#111111` · 보조 `#4a4a4a` · 흐림 `#6b6b6b` |

본문 텍스트 12개 항목의 명도 대비가 전부 4.5:1을 넘습니다(최저 5.33). 320 / 768 / 1024 / 1440px에서 가로 스크롤이 없고, 아이콘은 전부 인라인 SVG이며 `prefers-reduced-motion`을 존중합니다.

## 데이터 재생성

`data/report-data.js`는 이미 만들어져 있으므로 저장소만으로 문서가 동작합니다.

다시 만들려면 **원자료가 있는 로컬 작업 폴더에서만** 가능합니다. 원자료(댓글 CSV·원장)는 이 저장소에 포함하지 않았습니다.

```bash
python3 scripts/build_data.py     # data/report-data.js 재생성
python3 scripts/export_series_md.py  # docs/시리즈_방향_10가지.md 재생성
```

문구를 고치려면 `scripts/persona_copy.py`(페르소나·주제·키워드), `scripts/plan_copy.py`(시리즈 방향·레퍼런스), `scripts/pick_copy.py`(선택 시리즈 기획 과정)를 수정한 뒤 빌드를 다시 실행합니다.
